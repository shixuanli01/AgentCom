# ICR MedQA300 主要结果与审计报告

- **项目：** AgentCom / StateBridge
- **评估框架：** ICR（Independent Belief → Communication → Revision）
- **模型：** Qwen/Qwen3-4B
- **数据集：** MedQA，固定抽取 300 题
- **报告日期：** 2026-09-15
- **代码分支：** `icr-framework-20260915`
- **完整原始数据：** [GitHub Release `icr-medqa300-20260915`](https://github.com/shixuanli01/AgentCom/releases/tag/icr-medqa300-20260915)

## 1. 执行摘要

本次审计比较了文本通信（Text）、StateBridge 和 LatentMAS 作为同一冻结 ICR 协议中的通信通道时，对接收者一次修订行为的影响。最重要的结果不是三种方法最终准确率的细小差异，而是它们在“接受正确意见”和“抵抗错误意见”之间表现出明显不同的行为模式。

主要结论如下：

1. **Text 是目前唯一同时带来显著准确率收益和较好选择性的通信通道。** 在三个独立 seed pair 的主分析中，Text 准确率为 72.72%，StateBridge 为 71.06%；Text − StateBridge 为 **+1.67 个百分点**，95% item-cluster bootstrap CI 为 **[+0.83, +2.50]**。
2. **Text 和 StateBridge 接受正确发送者的能力相近，但 StateBridge 几乎同样强烈地追随错误发送者。** 三 seed 汇总中两者 CR 分别为 87.13% 和 85.15%，差异的 CI 跨 0；但 PR 分别为 37.62% 和 11.88%，Text 高 **25.74 个百分点**，95% CI **[16.04, 35.63]**。
3. **StateBridge 呈现强烈的非选择性覆盖行为。** 它的 FCS 为 85.00%，但 FWS 高达 89.00%，FollowSelectivity 为 −4.00%。也就是说，发送者正确时它会跟随，发送者错误时它更会跟随。该方向在三个 seed 中都稳定：每个 seed 均满足 StateBridge CR > PR，且 Text PR > StateBridge PR。
4. **LatentMAS 没有复现 StateBridge 的极端低 PR 模式。** 两 seed 对照中 LatentMAS 的 CR 为 31.34%、PR 为 67.16%；StateBridge 为 CR 88.06%、PR 13.43%。按预先约定的方向性判据，本次结果属于 **`B_directional_signature`**：StateBridge 的 CR−PR 为 +74.63 个百分点，而 LatentMAS 为 −35.82 个百分点。
5. **现有证据更支持“StateBridge 表示或传输方式特异的问题”，而不是“所有 latent communication 都会导致激进覆盖”。** 但这一结论仍限于 MedQA300；LatentMAS 只有两个完整 seed pair，跨数据集 Step 4 尚未开始，因此不能外推成广泛的机制性结论。

## 2. 审计问题与实验设计

### 2.1 核心问题

本次实验试图回答：当两个 agent 已经独立形成各自判断后，通信通道能否让接收者：

- 在自己错误、发送者正确时接受有用修正；
- 在自己正确、发送者错误时保留正确判断；
- 利用真正来自当前发送者的信息，而不是仅因“出现了一段消息”就改变答案；
- 在相同先验、相同修订提示词和相同采样 seed 下，表现出不同的通信行为。

### 2.2 冻结协议

每道题由 Agent A 和 Agent B 独立完成第一次作答，之后同时评估 A→B 和 B→A 两个方向。接收者保留自己的第一次推理和答案，只执行一次 revision generation。对于同一 `replication_id + item_id + direction`，各通信条件共享同一个 revision seed。

对照条件包括：

- `none`：无通信；
- `true_*`：当前题真实发送者的消息；
- `self_*`：接收者自己的消息；
- `other_*`：确定性映射得到的其他题消息。

Text 与 StateBridge 的正式主分析包含三个完整 seed pair（00、01、02），每个 seed、每个条件均有 300 题 × 2 个方向 = 600 条记录，共 **12,600 条 directional-condition records**。LatentMAS 比较使用两个完整 seed pair（00、01），覆盖十个条件，共 **12,000 条记录**。

LatentMAS 没有重新采样发送者；缺失的内部状态由完全相同的缓存 sender token trajectory 通过 teacher forcing 重建，以维持通信通道比较的公平性。本实验把 LatentMAS 作为冻结 ICR 协议内的通信通道，而不是复现其原始四 agent pipeline。

### 2.3 不确定性估计

所有正式置信区间均使用 **10,000 次 item-cluster bootstrap**。每次重采样 MedQA item ID，并保留被抽中题目的所有方向和所有纳入的 replication。该方法处理了同一道题两个方向之间的相关性；它主要支持对这 300 道题总体的推断，不应被解释为已经充分覆盖“可能的 seed 分布”。

## 3. 指标定义

| 指标 | 含义 | 理想方向 |
| --- | --- | --- |
| Acc | 修订后的总体准确率 | 高 |
| CR | Correction Rate：接收者原先错误、发送者正确时，被修正为正确的比例 | 高 |
| PR | Preservation Rate：接收者原先正确、发送者错误时，仍保持正确的比例 | 高 |
| SI | Selectivity Index，定义为 (CR + PR) / 2 | 高 |
| SRA | 仅在发送者与接收者正确性不一致的子集上，修订后正确的比例 | 高 |
| FCS | 发送者正确、接收者错误且答案不同时，接收者采用发送者答案的比例 | 高 |
| FWS | 发送者错误、接收者正确且答案不同时，接收者采用错误发送者答案的比例 | 低 |
| FollowSelectivity | FCS − FWS；区分选择性采纳与盲目跟随 | 高 |
| SR | 双方都错时被修正为正确的比例 | 高，但本实验不是主指标 |
| SCR | 双方都对时保持正确的比例 | 高 |

CR 或 FCS 单独很高并不能证明通信有效。如果 FWS 同样很高、PR 很低，更合理的行为描述是“强发送者跟随”或“信念覆盖”，而不是选择性利用信息。

## 4. Text 与 StateBridge：三 seed 主结果

### 4.1 汇总指标

| 通道 | Acc | CR | PR | SI | SRA | FCS | FWS | FollowSelectivity |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| None | 71.50% | 2.97% | 97.03% | 50.00% | 50.00% | 3.00% | 3.00% | 0.00% |
| Text | **72.72%** | **87.13%** | **37.62%** | **62.38%** | **62.38%** | **87.00%** | 63.00% | **24.00%** |
| StateBridge | 71.06% | 85.15% | 11.88% | 48.51% | 48.51% | 85.00% | **89.00%** | −4.00% |

### 4.2 Text − StateBridge 的配对差异

| 指标 | 差异 | 95% item-cluster bootstrap CI | 解读 |
| --- | ---: | ---: | --- |
| Acc | **+1.67 pp** | **[+0.83, +2.50]** | Text 的最终准确率更高 |
| CR | +1.98 pp | [−7.63, +11.46] | 没有清晰差异 |
| PR | **+25.74 pp** | **[+16.04, +35.63]** | Text 更能抵抗错误发送者 |
| SI | **+13.86 pp** | **[+6.84, +20.98]** | Text 的校正—保留平衡更好 |
| SRA | **+13.86 pp** | **[+6.84, +20.98]** | 不一致子集上 Text 更准确 |
| FCS | +2.00 pp | [−7.69, +11.57] | 接受正确发送者的程度相近 |
| FWS | **−26.00 pp** | **[−36.11, −16.16]** | Text 显著减少盲从错误发送者 |
| FollowSelectivity | **+28.00 pp** | **[+13.79, +42.42]** | Text 更具选择性 |

### 4.3 跨 seed 稳定性

| Seed pair | Text CR | Text PR | StateBridge CR | StateBridge PR |
| --- | ---: | ---: | ---: | ---: |
| 00 | 91.43% | 42.86% | 82.86% | 5.71% |
| 01 | 84.38% | 34.38% | 93.75% | 21.88% |
| 02 | 85.29% | 35.29% | 79.41% | 8.82% |

三个 seed 中，StateBridge 的 CR 都明显高于 PR；Text 的 PR 都高于 StateBridge。数值大小随 seed 改变，但核心方向没有翻转。

### 4.4 行为解释

StateBridge 并不是“没有影响”。相反，它对接收者具有很强影响：CR 和 FCS 都很高。但高达 89.00% 的 FWS 表明，这种影响基本没有可靠地区分发送者对错。它带来的修正和破坏接近互相抵消，因此总体准确率没有收益。

Text 也会大量跟随发送者，但保留了更多抵抗错误意见的能力。因此，Text 的优势主要不是“更愿意听正确意见”，而是“更少盲从错误意见”。

## 5. LatentMAS：两 seed 通道比较

### 5.1 同范围汇总指标

下表只使用 LatentMAS 已完成的 seed00/01，因此可在完全相同的样本范围内比较四个通道。

| 通道 | Acc | CR | PR | SI | SRA | FCS | FWS | FollowSelectivity |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| None | 71.42% | 4.48% | 95.52% | 50.00% | 50.00% | 4.55% | 4.55% | 0.00% |
| Text | **72.83%** | **88.06%** | 38.81% | **63.43%** | **63.43%** | **87.88%** | 62.12% | **25.76%** |
| StateBridge | 71.42% | **88.06%** | 13.43% | 50.75% | 50.75% | **87.88%** | **87.88%** | 0.00% |
| LatentMAS | 71.17% | 31.34% | **67.16%** | 49.25% | 49.25% | 30.30% | 33.33% | −3.03% |

### 5.2 关键配对结果

- Text − StateBridge Acc：**+1.42 pp**，95% CI **[+0.42, +2.42]**。
- Text − StateBridge PR：**+25.37 pp**，95% CI **[+12.68, +38.57]**。
- Text − LatentMAS Acc：**+1.67 pp**，95% CI **[+0.67, +2.75]**。
- StateBridge − LatentMAS Acc：+0.25 pp，95% CI [−0.67, +1.17]，没有清晰差异。
- StateBridge − LatentMAS CR：**+56.72 pp**，95% CI **[+45.45, +67.86]**。
- StateBridge − LatentMAS PR：**−53.73 pp**，95% CI **[−66.67, −39.74]**。

LatentMAS 的最终准确率并不优于 StateBridge，但其行为机制显著不同：它既不强烈接受正确发送者，也没有像 StateBridge 那样极端破坏接收者原有正确答案。因此，本次方向性证据为：

```text
StateBridge: CR − PR = +74.63 pp
LatentMAS:   CR − PR = −35.82 pp
Classification: B_directional_signature
```

这里的 Pattern B 只表示预先定义的方向性签名，不等同于已经证明某个普遍机制。

在相同两 seed 范围内，比较真实消息与无消息、自身消息、其他题消息：

| --- | ---: | ---: |

| Text true − self | **+1.50 pp** | **[+0.67, +2.42]** |

Text 的三个准确率对照 CI 均高于 0，支持其真实当前题消息具有正向、例子特异的效用。StateBridge 对行为有强影响，但准确率效用接近 0；LatentMAS 的现有准确率效用同样没有清晰偏离 0。

## 7. 计算与通信成本

以下为两 seed 范围内每条 revision 的平均记录值：

| 条件 | 平均 payload | 平均 revision 输入 token | 平均生成 token | 平均 revision 时间 | 额外通信时间 |
| --- | ---: | ---: | ---: | ---: | ---: |
| None | 0 | 802.77 | 665.44 | 15.71 s | — |
| true_text | 1,763 bytes | 1,222.90 | 566.18 | 13.28 s | — |
| true_statebridge | 327,680 bytes | 889.77 | 446.76 | 10.55 s | — |
| true_latentmas | 329,222,676 bytes | 825.77 | 377.69 | 8.35 s | 0.37 s |

StateBridge 的前缀注入减少了文本输入 token，并在当前硬件上缩短了 revision generation 时间，但逻辑 payload 约为 Text 的 186 倍。LatentMAS 当前实现记录的 KV 类 payload 估算约 314 MiB/条、10 个 latent steps；尽管 revision generation 较快，其通信对象体积远高于另外两种通道。这里的 payload 是当前实现记录的逻辑未压缩大小，不应直接等同于跨机器网络传输开销。

## 9. 结论边界

当前证据足以支持以下审慎结论：

- 在该 MedQA300 ICR 设置中，Text 的通信选择性和最终准确率优于 StateBridge。
- StateBridge 的主要问题不是影响不足，而是无法可靠区分正确与错误发送者，表现为极高 FWS 和极低 PR。
- LatentMAS 没有表现出 StateBridge 同样的激进覆盖签名，因此“低 PR 是所有 latent communication 的共同失败模式”不受当前数据支持。

当前证据**不能**支持：

- 将结果直接推广到其他推理数据集或更大模型；
- 声称已经识别 StateBridge 行为的内部因果机制；
- 声称 LatentMAS 普遍优于或劣于 StateBridge；两者准确率差异的 CI 跨 0；
- 把两个 LatentMAS seed 当作充分的跨 seed 稳健性证明。

另一个重要限制是 CR/PR 的机会子集较小：三 seed pooled 中每个真实通道的 CR 和 PR 分母各为 101，两 seed比较中各为 67。因此必须优先阅读配对 bootstrap CI，而不能只看点估计。

## 10. 建议的下一步

1. 按冻结协议执行 Step 4A：在新的推理 benchmark 上先跑 `none / true_text / true_statebridge / true_latentmas` 核心条件。
2. 若跨数据集方向仍一致，再执行 Step 4B 的 self/other 因果对照。
3. 在形成 LatentMAS 稳健性结论前，至少补充第三个 LatentMAS seed；如果成本允许，恢复至原计划的五 seed。
4. 对 StateBridge 进行机制诊断时优先检查注入强度、位置和接收者表示覆盖，而不是根据当前结果调 prompt；任何改法都应作为新方法，在冻结基线之外重新注册实验。
5. 效率比较应同时报告生成时延、输入 token、逻辑 payload、峰值显存和跨设备传输成本，避免仅用 revision latency 判断端到端效率。
