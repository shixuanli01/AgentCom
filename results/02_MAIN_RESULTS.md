## 通道

| **Keep Initial** | 无。receiver 永不修改 | 解析式参考，零 GPU |

| **Answer Only** | 仅 sender 的规范化答案字符串 | 本研究新增的下界基线 |
| **Full Text** | sender 的完整推理文本 | 已发表做法 |

`No Message` 与 `Keep Initial` 的差别很重要：`No Message` 里 receiver 仍然被要求走一遍修订，
所以它的 SI − 50 > 0 的部分**全部来自修订过程自身的噪声**，与任何通信无关。

## 读出来的四件事

### 1. 没有任何通道稳定取胜

按 SI − 50 排名，每个数据集的赢家都不同：

```
MedQA    StateBridge +12.93  >  Full Text +11.21  >  Answer Only  +9.48
GPQA-D   Full Text   +10.96  >  Answer Only +9.65  >  StateBridge  +7.89
ARC-C    Full Text    +7.65  >  StateBridge +7.14  >  LatentMAS    +2.04
GSM8K    StateBridge  +6.52  >  Answer Only +4.89  >  LatentMAS    +3.26
```

`Full Text` 在 GSM8K 上掉到 +1.63，比 `No Message` 的 +2.72 还低。
`LatentMAS` 在 MedQA 上是 +1.29，几乎等于不通信。
**通道排名随数据集翻转**，这是本审计最稳的一条结论。

### 2. 推理文本翻倍采纳率，但不一致地改变判别力

| 数据集 | 采纳率 π̄：Answer Only → Full Text | 判别力 Δπ：Answer Only → Full Text |
|---|---|---|
| MedQA | 29.3% → 69.0%（×2.4） | 19.0 → 22.4 |
| ARC-C | 37.8% → 73.0%（×1.9） | 2.0 → **15.3** |
| GSM8K | 32.1% → 48.9%（×1.5） | 14.1 → **4.3** |
| GPQA-D | 44.7% → 63.2%（×1.4） | 22.8 → 22.8 |

采纳率的方向在四个数据集上一致（全部上升，1.4–2.4 倍）；判别力的方向不一致
（GPQA 持平、MedQA 略升、ARC-C 大升、GSM8K 大降）。

**可以写的说法**：推理文本是一个说服信号，它稳定地让 receiver 更容易被推动；
推动的方向对不对，取决于数据集而不取决于文本本身。

**不能写的说法**："receiver 没有阅读推理"。采纳率翻倍说明 receiver 显然对文本有反应。
这套设计不采集 receiver 的处理过程，无法支持关于阅读行为的断言。

### 3. CR 和 PR 几乎总是此消彼长

`Full Text` 在四个数据集上都是高 CR / 低 PR（80.17/42.24、80.61/34.69、51.09/52.17、74.56/47.37）；
`No Message` 都是极低 CR / 极高 PR。没有一个通道做到两边都高。
这不是巧合——见 `04_DIAGNOSTICS.md` 的变化率参数化。

### 4. SR 和 SCR 上没有区分度

SR 全部落在 0.30%–2.55%（HumanEval+ 除外），SCR 全部落在 91.67%–100%。
四个通道在这两个分层上的差别都在噪声内。**信息全部在混合方向里**，
这也是为什么后续新增条件只跑混合方向是合理的取舍。
