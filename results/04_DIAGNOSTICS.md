# 04 — 解释性诊断

主表说明"没有通道稳定取胜"。这一份说明**为什么**。

## 1. SI 测的是接收方判别力，不是通信质量

表：[`tables/si_discrimination_identity.csv`](tables/si_discrimination_identity.csv)

把 receiver 的行为写成两个采纳概率：

```
π_CR = P(修订后答案 = sender 答案 | correction_opportunity)
π_PR = P(修订后答案 = sender 答案 | destruction_risk)
```

若 receiver 只在"保留自己"和"采纳 sender"之间二选一，则代数上

```
SI − 50  ≡  (π_CR − π_PR) / 2  =  Δπ / 2
```

**实测**：20 个非代码条件上 Pearson **r = 0.9879**，最大残差 2.17 个百分点。
残差全部由"改到第三个答案"（既非自己也非 sender）解释，该列已在表中给出。

**HumanEval+ 上恒等式无定义**，标记 `UNDEFINED`：自由形式代码几乎不可能与 sender 的输出字符串相等，
所以 π 本身没有意义。这是代码任务不可与其余数据集并列的第三条理由。

**结论**：SI 是 receiver 区分"该改"与"不该改"的能力的重标度。
它**不是**消息信息量的度量。一个通道 SI 高，意味着 receiver 在收到它时更会挑，
而不是它传了更多信息。这直接决定了论文该怎么措辞。

## 2. CR 与 PR 由单一参数（变化率）决定

表：[`tables/change_rate_parameterisation.csv`](tables/change_rate_parameterisation.csv)

在 20 个条件上，用混合方向的答案变化率作唯一自变量：

```
CR =   1.85 + 1.083 × 变化率      R² = 0.9693
PR = 104.79 − 0.964 × 变化率      R² = 0.9639
```

两条斜率是 **+1.08 和 −0.96**，即约等于 +1 和 −1。代入 SI：

```
SI ≈ 53.3 + 0.06 × 变化率
```

**变化率对 SI 的斜率几乎为零**。这就是主表里"CR 和 PR 此消彼长、没有通道两边都高"的定量解释：
通道之间的差别 96% 以上只是**让 receiver 改多少**的差别，而不是**让 receiver 改对多少**的差别。

一个通道要真正赢，必须打破这条单参数关系——即在同样的变化率下拿到更高的 CR。
`../parked_methods/` 里我们尝试过的每一条路线都没做到。

## 3. 找不到可用的、无需 ground truth 的正确性信号

如果存在一个 sender 端或 receiver 端的信号能预测"这个答案对不对"，
就可以据此选择性传输，从而打破上面那条关系。我们系统地找过，**没找到**。

### 3.1 自洽性（self-consistency）—— 已验证，已落盘

表：[`tables/diagnostics_self_consistency.csv`](tables/diagnostics_self_consistency.csv)
数据：`runs/medqa/self_consistency`，100 条记录，按正确/错误 50/50 分层抽样。

| 特征 | 预测正确性的 AUC |
|---|---:|
| `modal_agreement`（众数答案的重采样占比） | 0.4664 |
| `agreement_with_original`（重采样与原答案一致率） | 0.4914 |
| `distinct_answers`（重采样产生的不同答案数） | 0.5474 |

三个都贴着 0.5。更糟的是：

```
原答案准确率        50.00%
多数投票答案准确率   40.00%
```

**多数投票比直接用原答案更差 10 个百分点。** 自洽性在这个设置下不仅没有信号，还是有害的。

## 4. 这三条合起来说明什么

1. SI 测的是 receiver 的判别力（§1）。
2. 在现有通道下，判别力几乎不随通道变化，通道只改变变化率（§2）。
3. 之所以如此，是因为没有任何可用的正确性信号能让 sender 或 receiver 做选择性处理（§3）。

所以"设计一个在 SI 上稳定击败所有基线的通信通道"这个目标，
在当前协议与模型下**不是工程难度问题，而是信息论上的空缺**。
这正是把论文定位为**审计框架 + 解释性对照**而非"我们的方法更好"的依据。
